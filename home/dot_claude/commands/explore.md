# Intro

In the following messages, I will ask you to do something. You will keep in mind the exploration of the current project when you generate answers.

## Explore

First, use parallel subagents to find and read all files that may be useful to understand the current codebase. You should get a sense of best practices, followed conventions, architecture, code organisation and antyhing else that might be useful for you to implement a new feature in this codebase. The code you will generate will follow the practices already applied in the codebase.

## Report

Report back with your findings:

- what is the codebase about
- what is the tech stack used
- how is the code structured
- what features are implemented
- How is the database structured
- how is the frontend interacting with the backend
- how is the backend interacting with the frontend
- are there some restrictions I should know about
- How is authentication / authorization handled
- Understand the different routes
- etc.

The report should include anything you find useful that will help you answer questions about the codebase and implement new features
